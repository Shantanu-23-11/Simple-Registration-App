# Simple Registration App

A Java-based registration application developed as an Eclipse IDE
project. This repository contains the project source code and Eclipse
configuration files.

## Overview

The **Simple Registration App** is a beginner-friendly Java project
focused on a registration workflow. It provides a starting point for
understanding how a Java application can collect and process
registration information.

## Getting Started

### Prerequisites

-   Java Development Kit (JDK) installed
-   Eclipse IDE installed

### Run the Project in Eclipse

1.  Clone or download this repository.
2.  Open Eclipse IDE.
3.  Select **File → Import → Existing Projects into Workspace**.
4.  Choose the downloaded `Simple-Registration-App` folder.
5.  Select the project and click **Finish**.
6.  In the Package Explorer, open the source files under `src/main`.
7.  Locate the Java class containing the `main()` method.
8.  Right-click that class and select **Run As → Java Application**.
